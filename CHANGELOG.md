# Changelog

All notable changes to Joe's Narrative Pause are documented here.

## [1.0.0] - 2026-11-01

### Added

- Narrative Mode: the GM can freeze all player token movement with a keybind (default Shift+Space), a scene-control button, or the module API.
- A pulsing border glow (color configurable, on by default) frames the screen while Narrative Mode is active.
- A gold-bordered "Narrative Mode" banner at the top-center of the screen (text configurable).
- Players who try to move a token get a fading reminder (default "No Walking, GM Talking!"), with configurable text and duration.
- Settings for banner visibility to players, border visibility to players, and optionally driving Foundry's built-in pause.
